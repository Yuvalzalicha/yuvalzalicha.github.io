Accessibility

Accessibility statement

An interim statement describing the accessibility features currently built into this portfolio.

Current approach

The site uses semantic HTML, visible keyboard focus, a skip link, descriptive page titles, responsive layouts, and text-based navigation. Core content is intended to remain usable with a keyboard and on different screen sizes.

Current status

A broader accessibility audit is planned. This interim statement does not claim formal certification or complete conformance with a specific accessibility standard.

Report an issue

If a page, control, document, or link is difficult to use, please email yuvalzalicha@gmail.com and describe the page and the problem encountered.
